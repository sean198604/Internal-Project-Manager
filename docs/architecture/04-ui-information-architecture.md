# 04 · 信息架构与 UI Layout

> 风格：Minimal · Professional · Quiet · Dense but readable
> **这是内部工作台，不是 Landing Page。**

---

## 1. 页面信息架构

```
/login                                  免登录
│
├── /share/[token]                      免登录 · 干净展示页（剥离一切内部信息）
│
└── (workspace) 需登录
    ├── /dashboard                      首页：一眼看到有没有问题
    │
    ├── /projects                       项目列表（Table / Timeline / Dashboard 视图）
    │   ├── /projects/new
    │   └── /projects/[id]              项目详情
    │        └── Tabs: Overview · Updates · Documents · Deployment · Timeline · Lineage · History
    │
    ├── /my-department                  本部门项目（USER 主入口）
    │
    ├── /archive                        历史项目库（ADMIN / MASTER）
    │   └── /archive/[id]               档案详情（= 项目详情 + Software Asset Card）
    │
    ├── /ai                             AI Assistant
    │
    └── /settings                       ADMIN 专属（除 recycle-bin 外）
        ├── /settings/users
        ├── /settings/departments
        ├── /settings/project-types
        ├── /settings/audit-logs
        ├── /settings/recycle-bin       ADMIN + MASTER
        └── /settings/ai
```

### 1.1 路由守卫

| 路由组 | 守卫 |
|--------|------|
| `/login` | 已登录 → 跳 `/dashboard` |
| `/share/*` | 无会话要求，Token 独立校验 |
| `(workspace)/*` | middleware：未登录 → `/login` |
| `/settings/{users,departments,project-types,audit-logs,ai}` | `isAdmin` → 否则 403 页 |
| `/archive` | ADMIN / MASTER → 否则 403 |

```
┌──────────┬───────────────────────────────────────────────────┐
│          │  Topbar (sticky, h=56)                            │
│  Sidebar │  [面包屑]              [搜索 ⌘/] [N 新项目] [头像]  │

│          │                                                   │
│          │                                                   │
└──────────┴───────────────────────────────────────────────────┘
```

### 3.1 设计 Token（Light 主题 · 内部工作台）

| 类别 | Token | 值 | 用途 |
|------|-------|-----|------|
| 背景 | `--bg` | `#FFFFFF` | 页面底 |
| 面板 | `--surface` | `#FAFAFA` | 卡片 / 表头 |
| 侧栏 | `--sidebar` | `#0F172A`（深色） | 导航区，白字 |
| 边框 | `--border` | `#E5E7EB` | 分隔线 |
| 主文 | `--fg` | `#111827` | |
| 次文 | `--fg-muted` | `#6B7280` | |
| 强调 | `--accent` | `#2563EB` | 主按钮 / 链接 / Focus ring |
| 正常 | `--ok` | `#16A34A` | NORMAL |
| 风险 | `--warn` | `#EA580C` | AT_RISK / 即将到期 |
| 危险 | `--danger` | `#DC2626` | DELAYED / OVERDUE |
| 中性 | `--neutral` | `#6B7280` | ON_HOLD / STALE |

> **不使用渐变背景、3D、Aurora、粒子、Beams。** 动效仅限：Modal 淡入（150ms）、Hover 变色、表格行展开。

### 3.2 排版与密度

| 项 | 值 |
|---|---|
| 正文字号 | 14px |
| 表格字号 | 13px |
| 表格行高 | 44px |
| 卡片圆角 | 8px |
| 按钮高度 | 32px（小）/ 36px（默认） |
| 内容最大宽 | 1440px 居中 |
| 内边距 | 24px |

### 3.3 快捷键（仅 3 个）

| 键 | 行为 |
|---|------|
| `N` | 新建项目 |
| `/` | 聚焦全局搜索 |
| `Esc` | 关闭 Modal / 抽屉 |

## 4. 关键页面结构

### 4.1 Dashboard（ADMIN / MASTER）

```
┌ 数字卡片区（6 个，一行 6 列 / 平板 3 列）────────────────────┐
│ 总项目 128 │ 进行中 23 │ 待验收 5 │ 延期 7 │ 有风险 4 │ 7天内到期 9 │
└──────────────────────────────────────────────────────────┘

┌ 需要关注 Attention ──────────────┬ 最近动态 ─────────────────┐
│ ⚠ 延期项目（按延期天数排序）      │ 最近完成（5 条）           │
│ 🔶 高优先级（P0/P1）             │ 最近归档（5 条）           │
│ ⏳ 7 天内到期                    │                          │
│ 💤 长期未更新 >7 天              │ 档案不完整 ⚠（n 条）       │
└─────────────────────────────────┴──────────────────────────┘

┌ 简单分布（自绘 SVG 条形，非图表库）──────────────────────────┐
│ 按状态分布  ▓▓▓▓▓▓░░░░  进行中 23                            │
│ 按部门分布  ▓▓▓▓░░░░░░  销售部 18                             │
└──────────────────────────────────────────────────────────┘
```

**Dashboard 唯一目的：打开就知道项目有没有问题。不加图表炫技。**

### 4.3 项目列表 `/projects`

```
┌ 工具栏 ────────────────────────────────────────────────────┐
│ [搜索框]  [部门▾] [类型▾] [负责人▾] [状态▾] [健康▾] [优先级▾] │
│ 视图: [Table] [Timeline] [Dashboard]          排序: 最近更新▾ │
└──────────────────────────────────────────────────────────┘

表格列：
编号 │ 项目名称 │ 系统名称 │ 部门 │ 类型 │ 负责人 │ 状态 │ 健康 │ 进度 │ 预计完成 │ 最近更新 │ 标记
                                                                  ↑
                                              状态徽章 + 派生标（延期/即将到期/未更新）

分页：20（默认） / 50 / 100
```

- 支持 Inline Edit：状态、健康状态、负责人、优先级、进度、预计完成日期
- 每行 hover 显示「快速更新」入口

### 4.4 项目详情 `/projects/[id]`

```
┌ 第一屏（无需滚动即可见全部关键信息）─────────────────────────┐
│  PRJ-2026-0003                              [进行中] [延期] │
│  采购审批优化                                                │
│  ─────────────────────────────────────────────────────────  │
│  需求部门: 采购部   负责人: 张三   类型: 功能优化   优先级: P1  │
│  开始: 2026-08-01   预计完成: 2026-09-01 (⚠ 已延期 5 天)      │
│  进度: ████████░░ 80%        最近更新: 2026-08-25 (11 天前 💤) │
└──────────────────────────────────────────────────────────┘

┌ Tabs ─────────────────────────────────────────────────────┐
│ Overview │ Updates │ Documents │ Deployment │ Timeline │ Lineage │ History │
└──────────────────────────────────────────────────────────┘
```

| Tab | 内容 | USER 可见性 |
|-----|------|:----------:|
| **Overview** | 目标 / 需求 / 验收标准 Checklist / 关键字段 | ✅ |
| **Updates** | 更新时间流（进度·状态·内容·问题·下一步）+ 新增更新 | ✅（本部门可新增） |
| **Documents** | 文档 + 截图，按类型分组，版本管理 | 部分（内部文档隐藏） |
| **Deployment** | 多环境部署卡片 | ❌ **仅 ADMIN/MASTER** |
| **Timeline** | 全生命周期事件（Aceternity Timeline 视觉，克制处理） | 部分 |
| **Lineage** | 父子/分支谱系树 | ✅ |
| **History** | 字段变更记录（前值/后值/人/时间/原因） | ❌ **仅 ADMIN/MASTER** |

右上角操作：`编辑` · `添加更新` · `问 AI` · `分享` · `⋯`（归档/迁移/合并/分支/删除）

## 5. 组件清单

### 5.1 自研（业务组件）

`ProjectCard` · `ProjectTable` · `StatusBadge` · `HealthBadge` · `DerivedFlag`（延期/到期/未更新）· `ProgressBar` · `UpdateFeed` · `UpdateForm` · `DocumentList` · `FileUploader`（Aceternity File Upload 去动效）· `DeploymentCard` · `TimelineList` · `LineageTree` · `HistoryTable` · `ArchiveChecklist` · `AssetCard` · `ShareLinkManager` · `FilterBar` · `EmptyState` · `MetricCard` · `DistributionBar`

### 5.2 shadcn/ui

`Button` · `Input` · `Select` · `Table` · `Dialog` · `Tabs` · `Badge` · `Tooltip` · `DropdownMenu` · `Toast` · `Skeleton` · `Pagination` · `Checkbox` · `Textarea` · `AlertDialog` · `Card` · `Separator` · `Sheet`（移动端抽屉）

### 5.3 Aceternity（**克制取用**）

| 组件 | 用法 | 处理 |
|------|------|------|
| Sidebar | 主导航 | 去动画，保留折叠/响应式 |
| Timeline | 项目时间线 | 保留结构，去掉滚动缩放动效 |
| File Upload | 文档上传 | 保留拖拽区，去边框流光 |
| Tabs | 项目详情 Tab | 保留下划线指示 |
| Empty State | 空列表 | 极简 |
| Card / Modal / Tooltip | 通用 | 用 shadcn 版本即可 |

**禁用**：Aurora Background · Background Beams · 3D Card · Vortex · Sparkles · 任何背景特效

## 6. 响应式

| 断点 | 表现 |
|------|------|
| ≥ 1440px | 完整布局，内容居中 |
| 1024–1439px | 侧栏默认折叠为 64px，表格横向滚动 |
| 768–1023px（平板） | 侧栏抽屉，卡片单列，表格关键列优先（编号/名称/状态/进度） |
| < 768px（手机） | 全部单列；表格转为卡片列表；支持查看/搜索/更新/归档查看/简单编辑 |

移动端优先级：查看项目 · 搜索 · 查看更新 · 查看归档 · 简单编辑。

## 7. 空状态与错误态

| 场景 | 处理 |
|------|------|
| 无项目 | EmptyState + 「创建第一个项目」按钮 |
| 无搜索结果 | 「没有找到匹配的项目」+ 清除筛选 |
| 无权限 | 404 页（**不显示 403，避免泄露资源存在性**）—— 菜单级才用 403 页 |
| 加载中 | Skeleton（表格骨架屏） |
| 操作失败 | Toast：「操作失败，请稍后重试」+ 错误码（可复制，便于报障） |
| AI 不可用 | 降级提示：「AI 服务暂时不可用，你可以使用搜索功能」，其余功能正常 |
